#  Advertising System

Система таргетированной рекламы, которая подбирает объявления для пользователей на основе ML‑скоров, ограничивает показы и клики уникальными пользователями, предоставляет API для рекламодателей и администраторов. Проект написан на **Spring Boot** с использованием **JPA/Hibernate**, **PostgreSQL**, **Spring Security (JWT)** и интеграцией с **Telegram-ботом**.

---

##  Бизнес-логика

- **Рекламодатель** создаёт объявление: указывает лимит показов и кликов, цены, текст, даты активности.
- **Объявление** может иметь **таргетинг** (пол, возраст, локация).
- **Пользователь** просматривает подходящие объявления (сортировка по ML‑скору).
- **Показ** засчитывается один раз на пользователя для каждого объявления.
- **Клик** засчитывается один раз на пользователя для каждого объявления (уникальность).
- **ML‑скор** вычисляется на основе истории кликов пользователя по рекламодателям.
- **Администратор** может управлять всем через API.

##  Основные API эндпоинты

### Рекламодатели
| Метод | Эндпоинт | Описание |
|-------|----------|-----------|
| POST | `/api/advertisers` | Создать рекламодателя |
| GET | `/api/advertisers` | Список всех |
| DELETE | `/api/advertisers/{id}` | Удалить (только свои) |

### Объявления
| Метод | Эндпоинт | Описание |
|-------|----------|-----------|
| POST | `/api/announcements` | Создать объявление (с таргетингом) |
| GET | `/api/announcements` | Все объявления |
| GET | `/api/announcements/{id}` | Получить одно |
| PUT | `/api/announcements/{id}` | Обновить (текст, название) |

| POST | `/api/announcements/{id}/impression` | Засчитать показ |
| POST | `/api/announcements/{id}/click` | Засчитать клик |

### Пользователи (клиенты)
| Метод | Эндпоинт | Описание |
|-------|----------|-----------|
| POST | `/api/clients/register` | Регистрация |

| GET | `/api/clients/me` | Профиль |

| Метод | Эндпоинт | Описание |

##  Логика уникальности показов и кликов

- **Показы**: запоминаются в отдельной сущности `Impression` (связка `announcement_id` + `client_id`). При повторном показе тому же клиенту – не засчитывается.
- **Клики**: аналогично через `ClickedClient` (один клик на объявление на пользователя).
- **ML‑скор**: обновляется при каждом клике (увеличивается для пары advertiser+client).

1. Установить PostgreSQL, создать БД `advertising_db`.
2. Настроить `application.properties`:
   ```properties

   spring.datasource.username=postgres
   spring.datasource.password=your_password
   spring.jpa.hibernate.ddl-auto=update
